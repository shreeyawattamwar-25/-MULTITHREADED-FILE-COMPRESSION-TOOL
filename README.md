The Speed Demon: Multithreaded Compression 💨
This task was about building a file compression program in C++ that was seriously fast. The goal wasn't just to squish files (compress them), but to prove that you could do it way faster than normal by using multithreading.

Divide and Conquer: Instead of one main thread slowly crunching the whole file, the program first broke the huge file into small, equal chunks.

Parallel Power: Each chunk was then handed off to its own separate thread (a worker on a different CPU core). All the workers compressed their tiny piece at the exact same time.

The Proof: By running this processing in parallel, the total time required was drastically reduced. The final program had to measure this time difference to demonstrate the clear performance gain that comes from using modern CPU cores effectively.

In short, you built a high-performance utility that showed off advanced skills in concurrency and systems optimization, all without relying on easy tools like std::vector!
